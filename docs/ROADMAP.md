# Roadmap

## V1.0 — 当前锁定范围

- [x] 分享文本 URL 提取与四平台识别
- [x] 视频元数据预览
- [x] 4K/1080p/720p/最佳质量选择
- [x] MP4/MKV 封装
- [x] 并发任务、进度、取消、历史与 Finder 定位
- [x] Safari/Chrome/Firefox/Edge/Brave Cookie 选项
- [x] WinHarbor 同源三主题、静态/动态壁纸、透明度和模糊调节
- [x] 离线工具链打包、ad-hoc 签名、真实公开测试视频验收

## 明确不做

- DRM 绕过、会员权益规避、帐号风控规避。
- 画面水印的 AI 擦除、模糊、裁切或重绘。
- 批量下载列表/播放列表。
- App Store 上架、公证和自动更新服务。
